┌──────────────────────────────────────────────────────────────┐
│  PASO 1: Abrir Wokwi                                        │
└──────────────────────────────────────────────────────────────┘

1. Ve a: https://wokwi.com
2. Inicia sesión (o crea cuenta gratis)
3. Click en "New Project" → "ESP32"


┌──────────────────────────────────────────────────────────────┐
│  PASO 2: Copiar el Código                                   │
└──────────────────────────────────────────────────────────────┘

Opción A:
  • Abre: wokwi/esp32_dht22_render.ino
  • Copia TODO el contenido
  • Pega en el editor de Wokwi

Opción B:
  • Abre: WOKWI-RENDER-PASO-A-PASO.md
  • Copia el código completo de la sección "Paso 2"
  • Pega en Wokwi


┌──────────────────────────────────────────────────────────────┐
│  PASO 3: Agregar Sensor DHT22                               │
└──────────────────────────────────────────────────────────────┘

En Wokwi:
  1. Click en "+" (arriba derecha)
  2. Click en "diagram.json"
  3. Copia el contenido de: wokwi/diagram.json
  4. Pega en Wokwi


┌──────────────────────────────────────────────────────────────┐
│  PASO 4: Ejecutar                                           │
└──────────────────────────────────────────────────────────────┘

1. Click en ▶️ "Start Simulation"
2. Abre el Serial Monitor (icono de terminal)
3. Espera a ver: "✅ HTTP 201"


┌──────────────────────────────────────────────────────────────┐
│  PASO 5: Ver Dashboard                                      │
└──────────────────────────────────────────────────────────────┘

Abre en otra pestaña:
  👉 https://ecosistema-simulado.onrender.com

Deberías ver datos actualizándose cada 5 segundos

║  ✅ VERIFICACIÓN                                            ║
╚══════════════════════════════════════════════════════════════╝

  ✅ HTTP 201

Dashboard debe mostrar:

║  🆘 SI ALGO NO FUNCIONA                                     ║

1. Verifica la URL en el código (línea ~26):
   const char* serverUrl = "https://ecosistema-simulado.onrender.com/sensors/data";

2. Verifica conexiones del DHT22:
   VCC  → 3V3
   DATA → GPIO15
   GND  → GND

3. Reinicia la simulación (⏸️ luego ▶️)

4. Revisa el Serial Monitor para ver mensajes de error
